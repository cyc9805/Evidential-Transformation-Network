## Overview

Deep neural networks often produce overconfident predictions despite achieving strong accuracy.

**Evidential Transformation Network (ETN)** is a lightweight post-hoc framework that transforms pretrained models into evidential models without retraining the backbone network, enabling reliable uncertainty estimation with minimal computational overhead.
